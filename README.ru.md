# MagicKeys

Клавиатуры Apple в Windows 11: медиаклавиши, сочетания macOS, модификаторы, навигация Fn и раскладки Apple.

![platform](https://img.shields.io/badge/platform-Windows%2011-lightgrey) ![release](https://img.shields.io/github/v/release/rstrlnkv/MagicKeys?include_prereleases) ![downloads](https://img.shields.io/github/downloads/rstrlnkv/MagicKeys/total) ![licence](https://img.shields.io/github/license/rstrlnkv/MagicKeys)

[English](README.md) · **Русский**

MagicKeys заставляет Magic Keyboard (и другие клавиатуры Apple) работать в Windows так, как
напечатано на клавишах. Собственный драйвер ей не нужен, в систему она ничего не ставит: раскладки
Apple подменяют символы на лету и в Windows не регистрируются. По кнопке программа умеет забрать
у Apple родной драйвер клавиатуры Boot Camp и поставить его.

## Установка

1. Скачайте `MagicKeys-<версия>-x64.msi` со страницы [выпусков](https://github.com/rstrlnkv/MagicKeys/releases).
2. Запустите его. Установка идёт на всю машину, поэтому Windows спросит права администратора.
3. Запустите MagicKeys из меню «Пуск». При закрытии окна программа остаётся в области уведомлений;
   выход — из меню значка.

Ключи командной строки: `--tray` — запуск сразу в значок, без окна; `--log` — журнал
в `%AppData%\MagicKeys\log.txt`.

Следующие версии ставятся из самой программы: «О программе» → «Проверить». Удаление — в «Параметры» → «Приложения».

## Возможности

| Возможность | Что делает |
|---|---|
| Функциональные клавиши | F1–F12 делают то, что на них напечатано, с учётом поколения клавиатуры (у полноразмерных ещё F13–F19); любой клавише можно назначить другое действие из закрытого списка; режим «медиа сразу» или «F-клавиши сразу» |
| Заменитель Fn | Fn до Windows не доходит, поэтому её роль играет выбранная клавиша (правый ⌥, клавиша Windows, правый control или Caps Lock), с навигацией macOS: `Fn+←/→/↑/↓` → Home, End, PgUp, PgDn; `Fn+Backspace` → Delete |
| Сочетания macOS | ⌘C копирует, ⌘← уходит в начало строки, ⌥← прыгает через слово; ⌘+Tab как Alt+Tab |
| Модификаторы | Оба control, ⌥, обе ⌘ и Caps Lock направляются куда угодно или выключаются; три готовые схемы |
| Раскладки Apple | 33 встроенные раскладки с мёртвыми клавишами; подменяются только клавиши, которые отличаются от раскладки Microsoft для того же языка; каждому языку ввода Windows — своя раскладка Apple |
| Яркость экрана | Клавиши яркости работают: внешние мониторы по DDC/CI, встроенная панель через WMI, со своим индикатором на экране |
| Заряд клавиатуры | Показывает заряд, которого Windows не показывает |
| Ваша клавиатура | Схема той модели, которую узнала программа; клавиши, доходящие до Windows, обведены и подсвечиваются при нажатии |
| Драйвер Apple | Находит пакет Boot Camp на серверах Apple, скачивает, распаковывает и ставит драйвер клавиатуры; умеет и удалить его |
| Обновления | Проверяет GitHub по кнопке; канал Stable или Dev; ставит только установщик, подписанный сертификатом проекта |

## Требования

- **ОС:** Windows 11, x64. Программа работает на .NET Framework 4.x, который входит в Windows.
- **Клавиатуры:** клавиатуры Apple по Bluetooth или USB. Переназначения действуют на весь ввод
  с клавиатуры: Windows не сообщает, с какого устройства пришло нажатие. Пункт «Только с Magic
  Keyboard» заставляет программу молчать, пока клавиатура Apple не подключена.
- **Права:** администратор нужен, чтобы поставить MSI и чтобы поставить или удалить драйвер Apple
  (`pnputil`). Сама программа работает с правами пользователя и ставит низкоуровневый перехват клавиатуры.
- **Сеть:** без нажатия кнопки — никуда. По кнопке программа обращается к:
  - `api.github.com` и `github.com` (и к серверу загрузок GitHub): проверка и скачивание обновления;
  - `swscan.apple.com` и `swcdn.apple.com`: каталог обновлений Apple и пакет Boot Camp (около 700 МБ);
  - `www.7-zip.org`: официальный MSI 7-Zip, нужный для распаковки пакета Apple, если 7-Zip
    не установлен (его SHA-256 сверяется перед запуском).
- **Изменения вне своей папки:**
  - `%AppData%\MagicKeys\`: `settings.xml`, свои раскладки в `layouts\` и `log.txt` при `--log`;
  - `%LocalAppData%\MagicKeys\`: скачанный пакет Boot Camp (`bootcamp\`) и развёрнутый 7-Zip (`tools\`);
    программа предлагает кнопку, чтобы их удалить;
  - `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`: запись автозапуска, только если её включить;
  - драйвер клавиатуры Apple (`Keymagic2.inf`) в хранилище драйверов Windows вместе с его 24 раскладками
    «(Apple)», только если его поставить; смена поведения Fn пишет `OSXFnBehavior` в
    `HKLM\SYSTEM\CurrentControlSet\Services\KeyMagic2` (с запросом прав администратора).

## Сборка из исходников

Нужна Windows с .NET Framework 4.x. Для самой программы не нужны ни SDK, ни Visual Studio, ни NuGet.

```
scripts\build.cmd
```

Скрипт компилирует `src\` компилятором `csc.exe` из самого .NET Framework и кладёт `MagicKeys.exe`
в корень репозитория, рядом с `layouts\`. Номер сборки — число коммитов (`git rev-list --count HEAD`).

```
tests\run.cmd
```

запускает тесты.

```
installer\build-msi.cmd
```

собирает `MagicKeys-<версия>-x64.msi`. Набор WiX 3.14 он подтягивает через NuGet, поэтому нужна сеть.
Без сертификата выпуска пакет выйдет неподписанным: ставится он как обычно, но обновиться на него
программа откажется.

Как устроен код — в [ARCHITECTURE.md](ARCHITECTURE.md) (на английском).
