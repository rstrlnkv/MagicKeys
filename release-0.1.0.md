Первый выпуск. **Ранняя сборка** — на живой клавиатуре проверена не вся, поэтому канал Dev.

## Что она делает

Настраивает Apple Magic Keyboard в Windows 11 — без установки драйверов в систему.

**Сочетания как на маке.** ⌘C копирует, ⌘← уходит в начало строки, ⌥← прыгает через слово, ⌘Q закрывает окно. Шестьдесят сочетаний в трёх разделах, у каждого раздела свой выключатель, каждое сочетание выключается по отдельности. ⌘ с клавишей, которой в списке нет, делает то же самое с control.

**Верхний ряд.** F1–F12 дают громкость, яркость и перемотку — как на маке. Настоящие F-клавиши приходят с заменителем Fn: настоящую Fn Magic Keyboard в Windows не отправляет вовсе, её обрабатывает сама клавиатура. Fn+стрелки дают Home, End, PgUp, PgDn.

**Модификаторы.** Caps Lock как control, ⌘ на месте Ctrl, обмен ⌥ и ⌘ — готовыми схемами или по одной клавише.

**Раскладки Apple.** Тридцать три языка. Подменяются только те клавиши, которые в действующей раскладке Windows дают не то, что напечатано на клавише Apple; мёртвые клавиши работают. В систему ничего не ставится.

**Цифровой блок.** Клавиша ⌧ приходит в Windows как Num Lock и молча выключает блок; программа возвращает ей смысл. Клавиша «=» приходит кодом, которого никто не понимает, — программа печатает «=» сама.

**Яркость внешних мониторов** по DDC/CI — того, чего Windows не умеет вовсе: свои коды яркости она применяет только к встроенной панели ноутбука.

**Заряд батареи.** Windows его не показывает; программа спрашивает клавиатуру напрямую отчётом HID.

**Уживается с драйвером Boot Camp.** Если он забрал верхний ряд, программа ему уступает и говорит об этом прямо, а не притворяется, что настройки работают.

## Установка

Скачайте `MagicKeys-0.1.0-x64.msi` и запустите. Нужны права администратора — программа ставится в Program Files. Из требований только .NET Framework 4.x, он есть в Windows 11 из коробки.

Пакет подписан самодельным сертификатом: Windows покажет «издатель неизвестен». Отпечаток — `103850469089DEECC19D0DD6CE1D4DD3307601FA`, его же программа сверяет при обновлении и чужому пакету не поверит.

## Что важно знать заранее

**Переназначения действуют на весь ввод, а не только на клавиатуру Apple.** Низкоуровневый перехват Windows не знает, с какого устройства пришло нажатие, — это ограничение системы, а не недосмотр. Поэтому есть пункт «Только с Magic Keyboard»: с ним программа молчит, пока клавиатуры Apple нет.

**Клавиша ⏏ на Magic Keyboard в Windows не приходит вовсе** — её обрабатывает сама клавиатура, и драйвер тут не помогает. Настройка для неё есть и рассчитана на алюминиевые модели по USB; проверить этот путь было не на чем.

**Ранняя сборка.** Разбор нажатий проверяется стендом — 703 проверки, — но стенд отвечает за решения программы, а не за живое железо. Если клавиша повела себя странно, помогает страница «Диагностика» в режиме разработчика: она показывает, что именно дошло до Windows.

## Как это проверялось

Двадцать четыре прохода придирчивого разбора всего кода. Больше трёхсот исправленных дефектов, и почти все серьёзные — один класс: у клавиши оказывалось два хозяина или ни одного. Нажатие уходило одной дорогой, отпускание другой, и клавиша оставалась зажатой в Windows навсегда — снять её было нечем.

Правило дома: утверждение без команды под ним — это утверждение, а не факт. У каждой починки есть проверка в стенде и контрольный опыт: сначала показать, что проверка падает без починки.
