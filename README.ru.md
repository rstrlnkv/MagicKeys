# MagicKeys

Клавиатуры Apple в Windows 11. Медиаклавиши, сочетания macOS, модификаторы, навигация Fn
и раскладки Apple — клавиши делают то, что на них напечатано.

## Установка

Скачайте `MagicKeys-<версия>-x64.msi` со страницы [выпусков](https://github.com/rstrlnkv/MagicKeys/releases)
и запустите. Пакет ставится на всю машину, поэтому Windows один раз спросит права администратора.
MagicKeys запускается из меню «Пуск» и при закрытии окна остаётся в области уведомлений; выход —
из меню значка. `--tray` запускает её без окна, `--log` ведёт журнал в `%AppData%\MagicKeys\log.txt`.

Дальше MagicKeys обновляется сама: **«О программе» → «Проверить»** находит новый выпуск на GitHub
и запускает его установщик. Установщик без подписи сертификатом проекта не запускается никогда —
сверяется отпечаток сертификата, а не цепочка доверия. Канал **Stable** берёт только готовые
выпуски, **Dev** — ещё и ранние; переключатель — на странице «О программе».

## Возможности

| Возможность | Что делает |
|---|---|
| **Функциональные клавиши** | F1–F12 делают то, что на них напечатано, с учётом поколения клавиатуры, у полноразмерных — ещё F13–F19. Любой клавише можно дать другое действие из закрытого списка — ничего введённого человеком программа не запускает. Сначала медиа, как на маке, или сначала F-клавиши. |
| **Заменитель Fn** | Fn до Windows не доходит, поэтому её роль играет выбранная клавиша: правый ⌥, клавиша Windows, правый control или Caps Lock. С ней работают навигация macOS (`Fn+←/→/↑/↓` → Home, End, PgUp, PgDn; `Fn+Backspace` → Delete) и переключение режима F-клавиш. |
| **Сочетания macOS** | ⌘C копирует, ⌘← уходит в начало строки, ⌥← прыгает через слово, ⌘+Tab переключает окна. |
| **Модификаторы** | Оба control, ⌥, обе ⌘ и Caps Lock направляются куда угодно или выключаются — по одной клавише или одной из трёх готовых схем. |
| **Раскладки Apple** | 33 встроенные раскладки с рабочими мёртвыми клавишами, своя для каждого языка ввода Windows. Подменяются только клавиши, которые отличаются от раскладки Microsoft для того же языка; в систему ничего не ставится. |
| **Яркость** | Клавиши яркости работают: внешние мониторы по DDC/CI, встроенная панель через WMI, со своим индикатором на экране. |
| **Заряд** | Заряд клавиатуры, которого Windows не показывает. |
| **Ваша клавиатура** | Схема той модели, которую узнала MagicKeys. Клавиши, доходящие до Windows, обведены и подсвечиваются при нажатии. |
| **Драйвер Apple** | Находит пакет Boot Camp на серверах Apple, скачивает, распаковывает и ставит драйвер клавиатуры; по просьбе удаляет его. |

Программа говорит по-русски.

## Требования

Windows 11 на x64. Программа работает на .NET Framework 4.x, который входит в Windows; пакет — только
x64. Клавиатуры Apple работают по Bluetooth и USB. Переназначения действуют на весь ввод
с клавиатуры: Windows не сообщает, с какого устройства пришло нажатие. Пункт «Только с Magic
Keyboard» заставляет MagicKeys молчать, пока клавиатура Apple не подключена.

Права администратора спрашиваются дважды, и каждый раз — только когда нужны: чтобы поставить пакет
и чтобы поставить или удалить драйвер Apple (`pnputil`). Сама программа работает с вашими правами
и следит за клавиатурой через низкоуровневый перехват.

Пять адресов, к которым MagicKeys обращается по сети, каждый — только после нажатия кнопки:
`api.github.com` и `github.com` — проверка и скачивание обновления; `swscan.apple.com`
и `swcdn.apple.com` — каталог Apple и пакет Boot Camp (около 700 МБ); `www.7-zip.org` — официальный
установщик 7-Zip, если 7-Zip нет: без него пакет Apple не распаковать, и его SHA-256 сверяется
перед запуском.

Четыре вещи, которые MagicKeys может изменить за пределами своей папки. **Настройки** лежат
в `%AppData%\MagicKeys\` (`settings.xml`, свои раскладки в `layouts\`, журнал). **Пакет Apple**
и развёрнутый 7-Zip — в `%LocalAppData%\MagicKeys\`, а на странице драйвера Apple есть кнопка,
которая их удаляет. **Автозапуск** — значение в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`,
только если его включить. **Драйвер Apple** (`Keymagic2.inf`) ложится в хранилище драйверов Windows
вместе с 24 раскладками «(Apple)», только если его поставить; смена поведения Fn пишет
`OSXFnBehavior` в `HKLM\SYSTEM\CurrentControlSet\Services\KeyMagic2` с запросом прав администратора.

## Сборка из исходников

Нужна Windows с .NET Framework 4.x — ни SDK, ни Visual Studio, ни NuGet для самой программы.

```bat
scripts\build.cmd          :: src\ → MagicKeys.exe в корне репозитория
tests\run.cmd              :: тесты
installer\build-msi.cmd    :: MagicKeys-<версия>-x64.msi
```

`scripts\build.cmd` компилирует `src\` компилятором `csc.exe` из самого .NET Framework и нумерует
сборку числом коммитов. `installer\build-msi.cmd` подтягивает WiX 3.14 через NuGet, поэтому нужна
сеть; без сертификата выпуска пакет выйдет неподписанным — он ставится, но обновиться на него
MagicKeys откажется. Как устроен код — в [ARCHITECTURE.md](ARCHITECTURE.md) (на английском).
